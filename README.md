# 🍔 Food Delivery Business Performance — Data Visualization
A data visualization portfolio created to explore and communicate meaningful insights from a food delivery business dataset using **Python, Pandas, Matplotlib, and Seaborn**.

## 📌 Project Overview
This project focuses on understanding business performance through data visualization. Different charts are used to identify trends, compare categories, and analyze relationships between important business metrics.

## 🔍 Analysis Covered

* 📈 Orders and revenue trends over time
* 🏙️ Revenue comparison across cities
* 🍜 Performance of different cuisines
* 📢 Relationship between marketing spend and revenue
* 🚴 Delivery time and customer ratings
* 🌦️ Impact of weather conditions
* 📱 Performance of different order channels
* 🔄 Customer and business metric relationships
* 🔥 Correlation analysis using a heatmap

## 📊 Visualizations
The portfolio includes:

**Line Plot • Bar Chart • Scatter Plot • Histogram • Box Plot • Violin Plot • Count Plot • Correlation Heatmap**

Each visualization includes appropriate titles, labels, formatting, and a brief interpretation of the insights discovered.

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Jupyter Notebook / Google Colab**

## 🎯 Key Insights

The analysis highlights important patterns in **revenue, orders, customer satisfaction, delivery efficiency, marketing, cuisine preferences, weather conditions, and ordering channels**.

One of the strongest observations is the relationship between **delivery time and customer ratings**, showing the importance of efficient delivery in customer experience.


## 🎓 Learning Outcome

This project demonstrates practical skills in **data exploration, data preprocessing, statistical analysis, visualization, correlation analysis, and communicating data-driven business insights**.
